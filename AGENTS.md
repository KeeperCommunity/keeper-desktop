# Pull request review

Follow [.github/REVIEW_POLICY.md](.github/REVIEW_POLICY.md) when preparing or updating a pull request. Use [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md), select and verify the GitHub Copilot effort before the first review, and record actual review evidence. Keep draft and every-push automatic reviews disabled, batch material fixes before requesting another review, and obtain the required independent human approval and checks before merge.
