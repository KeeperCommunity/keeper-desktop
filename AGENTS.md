# Pull request review

Follow [.github/REVIEW_POLICY.md](.github/REVIEW_POLICY.md) when preparing or updating a pull request. Use [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md), select and verify the GitHub Copilot effort before the first review, and record actual review evidence. Keep draft and every-push automatic reviews disabled, batch material fixes before requesting another review, and retain all required checks before merge. Human developer review is optional.

Preserve current repository conventions. Before delivery, run feasible checks proportional to the change: documentation edits need formatting, links, and scoped diff checks; runtime changes need relevant checks. Human live verification takes place after agent delivery. Merge still requires the existing required checks; requested human feedback and its disposition must be recorded without making approval a merge gate.
